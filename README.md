# 🐍 Classic Snake Game (Java Full-Stack)

A modern, responsive, and cross-platform **Snake Game** built with pure **Java HttpServer** on the backend and custom **HTML5 Canvas & CSS3** on the frontend. Playable on both Desktop and Mobile devices!

🔗 **Live Demo:** [Play Snake Game Here](https://snack-game-1tdi.onrender.com)

---

## ✨ Features

- 📱 **Mobile & Desktop Friendly:** On-screen touch directional controls for mobile users & keyboard arrow navigation for PC players.
- 🎨 **Modern Aesthetics:** Aesthetic glassmorphism UI card overlaying a sleek nature background.
- ⚡ **Multiple Difficulty Levels:** Choose between **Easy**, **Medium**, and **Hard** speeds on the fly.
- 🔄 **Instant Reload:** Quick restart functionality without losing app state.
- ☕ **Pure Java Backend:** Powered by lightweight native `com.sun.net.httpserver.HttpServer` with dynamic static-file routing.
- 🐳 **Dockerized Deployment:** Containerized setup hosted on **Render**.

---

## 🕹️ How to Play

### Controls
- **Desktop:** Use **Up (▲), Down (▼), Left (◄), Right (►)** Arrow Keys on your keyboard.
- **Mobile:** Tap the on-screen **Directional Touch Buttons**.

### Objective
1. Eat as many red apples 🍎 as you can to grow your snake and increase your score.
2. Avoid crashing into the canvas boundaries or colliding with your own body.
3. Select your desired speed (**Easy / Medium / Hard**) and hit **Reload 🔄** anytime to start fresh!

---

## 🛠️ Tech Stack & Architecture

- **Backend:** Java (JDK 17) using `HttpServer` & `HttpHandler`
- **Frontend:** HTML5, CSS3 (Flexbox & Glassmorphism UI), JavaScript (HTML5 Canvas API)
- **Containerization:** Docker
- **Hosting & Cloud:** Render Cloud Platform
